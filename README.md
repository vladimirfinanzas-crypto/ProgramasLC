# Programas de Fomento al Comercio Exterior de México

Página interactiva y autónoma (un solo `index.html`) con una ciudad animada 2D donde cada edificio es un programa; fichas flotantes por programa (qué es, objetivos, instancias que lo regulan, empresas beneficiadas, apoyos y requisitos con lista de verificación), comparador de beneficios y orientador "¿cuál me conviene?".

Programas: IMMEX, PROSEC, Draw Back, Certificación IVA/IEPS, OEA, Recinto Fiscalizado Estratégico y Bancomext.

**Realizado por:** ROSA ELENA AVILES MENDEZ · JOSELYN ABRIL GUTIERREZ RODRIGUEZ · YAÑEZ VLADIMIR · CALEB SALAZAR DE LA ROSA

## Publicar en GitHub Pages
1. Crea un repositorio nuevo y sube `index.html`, `404.html`, `README.md` y `.nojekyll` a la raíz.
2. Settings → Pages → Deploy from a branch → rama `main`, carpeta `/ (root)` → Save.
3. En uno o dos minutos: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Nota
Material académico. Confirma requisitos y beneficios vigentes en la Secretaría de Economía (gob.mx/se), el SAT/ANAM y Bancomext (bancomext.com).
